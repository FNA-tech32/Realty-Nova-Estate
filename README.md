# Realty Nova Estate

A single-page real estate site for **Realty Nova Estate**. It is a static landing page built with HTML and CSS. There is no build step and no backend.

## What the page includes

- **Header and hero** — brand name, navigation, and a short introduction on the home background
- **Partner strip** — a row of partner marks under the hero
- **Listings** — a grid of modern homes, each with a photo, name, price, and a detail button
- **Feature blocks** — two highlights for affordable modern homes and long-term stays, each with an early-bird booking button
- **Newsletter** — an email signup for weekly property articles
- **Footer** — social links, locations, office contact, and legal links

## Run it locally

Open `index.html` in a browser. Styles and images load from the `Assets` folder, so keep that folder next to `index.html`.

## Project layout

```
index.html          Page markup
Assets/style.css    Layout and visual styles
Assets/Images/      Logo, listing photos, icons, and backgrounds
```
